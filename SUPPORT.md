# Support

## Where to get help

- Usage and integration help: https://www.hauntedmc.nl/support
- Bug reports: GitHub Issues, using the bug-report form
- Feature proposals: GitHub Issues, using the feature-request form
- Security concerns: [SECURITY.md](SECURITY.md)

## Before opening an issue

Include the HauntedMC Theme and FeatureFramework versions, Java and platform versions, the relevant MiniMessage or
Java usage, a minimal reproduction, and any error output.

Support and triage are best-effort and prioritized by impact and reproducibility.
